
1) Для локального запуска надо устаносить .net10 sdk и runtime
[Инструкции для разных ОС](https://learn.microsoft.com/ru-ru/dotnet/core/install/linux)


2) Далее запустить /backend/src/docker-compose.yaml


3) Запусить локально апишку используя ide или из cli с командой
"dotnet run -lp "Http.Local"" в директории проекта

Локальный SMTP по [http://localhost:8025](http://localhost:8025)
